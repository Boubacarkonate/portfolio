## The goal

A **personal project** to strengthen **web fundamentals** — HTML, CSS and JavaScript **with no framework** — by building a genuinely useful tool: a CSS style generator that saves time during integration.

## Features

- **live preview** of the result;
- CSS code **generation and export**;
- **real-time** interface;
- **premium features unlocked** via a payment (Lemon Squeezy, in **test mode**).

## Technical choices

- **Vanilla JavaScript** (no framework): a deliberate choice, to work in depth on **DOM** manipulation, **event** handling and **dynamic** style generation.
- **Lemon Squeezy**: to learn how to integrate a **payment / checkout** and unlock premium features — set up in **test mode**.

## What the project demonstrates

A solid grasp of **web fundamentals without a framework**, DOM manipulation, attention to interface detail, and a **first payment integration** (Lemon Squeezy).

> The code for this project is private: only the live demo is available.
