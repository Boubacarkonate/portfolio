## The goal

A **learning project** to train on **modern end-to-end full stack development** — a real management application rather than an isolated exercise. Target skills: building front and back in a single framework (Next.js), using a **typed ORM** (Prisma) on a relational database, and integrating a **real payment flow** (Stripe).

## Features

- **real-time** dashboard;
- product catalogue **filterable** by category;
- **online payments** via Stripe;
- **shared scheduling**;
- **CSV export** of data;
- built-in assistant.

## Technical choices

- **Next.js + TypeScript**: a single framework for rendering and API routes, with strict typing end to end.
- **Prisma + PostgreSQL**: a typed ORM for safe queries and clear migrations, on a **relational** database.
- **Stripe**: to learn how to integrate a full payment flow.
- **Tailwind CSS**: to prototype the interface quickly.

## What I worked on

Structuring a coherent full stack application (data model → API → interface), handling authentication and a payment journey, and exposing filterable, exportable data.

## What the project demonstrates

Being able to ship a **complete, deployed full stack application**: relational database, API, online payments and a polished interface.
