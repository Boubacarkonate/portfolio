## L'objectif

Un **projet d'apprentissage** pour me former au développement **full stack moderne de bout en bout** — plutôt qu'un exercice isolé, une vraie application de gestion. Les compétences visées : construire front et back dans un même framework (Next.js), utiliser un **ORM typé** (Prisma) sur une base relationnelle, et intégrer un **paiement réel** (Stripe).

## Les fonctionnalités

- tableau de bord en **temps réel** ;
- catalogue de produits **filtrable** par catégorie ;
- **paiement en ligne** via Stripe ;
- **planning partagé** ;
- **export CSV** des données ;
- assistant intégré.

## Les choix techniques

- **Next.js + TypeScript** : un seul framework pour le rendu et les routes API, avec un typage strict de bout en bout.
- **Prisma + PostgreSQL** : un ORM typé pour des requêtes sûres et des migrations claires, sur une base **relationnelle**.
- **Stripe** : pour apprendre l'intégration d'un flux de paiement complet.
- **Tailwind CSS** : pour prototyper l'interface rapidement.

## Ce que j'ai travaillé

Structurer une application full stack cohérente (modèle de données → API → interface), gérer l'authentification et un parcours de paiement, et exposer des données filtrables et exportables.

## Ce que le projet démontre

Savoir livrer une **application full stack complète et déployée** : base de données relationnelle, API, paiement en ligne et interface soignée.
